# APP 用户分享行为分析

## 项目简介
分析"什么样的用户更容易点击分享"，建立逻辑回归模型预测分享行为。

## 数据
- `某APP用户信息数据.csv`：14.7 万用户 × 6 列

## 方法
- **数据清洗**：剔除缺失值、异常值（概率超出 0~1）、极端值（在线时长超 99% 分位），共剔除 1586 条脏数据
- **对比分析**：分享 vs 未分享用户的特征差异
- **逻辑回归建模**：预测"是否点击分享"

## 结果
- 清洗后数据 145683 条
- 逻辑回归准确率 **60.8%**，低于 baseline（61%）
- **核心结论**：模型的概率预测与实际分享行为不一致，概率特征本身不可靠

## 技术栈
Python · pandas · scikit-learn · matplotlib
