# APP 用户分享行为分析

## 项目简介
围绕「什么样的用户会点击分享」，清洗并分析 14.7 万条用户行为数据，通过聚类进行用户分群。

## 数据
- `某APP用户信息数据.csv`：14.7 万用户 × 6 列

## 方法
- **数据清洗**：剔除缺失值、异常值（概率超出 0~1）、极端值（在线时长超 99% 分位），共剔除 1586 条脏数据
- **用户分群**：特征标准化后用 K-Means 聚类，将用户分成 3 类
- **对比分析 + 逻辑回归建模**：验证"分享概率"特征是否可靠

## 结果
清洗后数据 145683 条，聚类得到 3 类用户：

| 群体 | 占比 | 特征 |
|------|------|------|
| 愿意分享型 | 60% | 愿意分享概率 0.84 |
| 不愿分享型 | 39% | 不愿分享概率 0.84 |
| 超级重度用户 | 1.2% | 在线时长均值 13753 分钟 |

- 但三类用户的**实际分享率接近**（35% ~ 45%），逻辑回归准确率 60.8%，低于 baseline 61%
- **核心结论**：模型的分享概率预测与用户真实行为脱节，不能用于预测分享行为

## 技术栈
Python · pandas · scikit-learn（K-Means 聚类 / 逻辑回归）· matplotlib
